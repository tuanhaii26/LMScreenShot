## Tiếng Việt

### Giới thiệu
LMScreenShot là công cụ hỗ trợ người dùng chụp ảnh toàn màn hình, giúp nhận diện, chụp tương tác hoặc chụp tức thì từng màn hình riêng biệt.

### Các tính năng chính

1. Quản lý đa màn hình và Chụp tương tác
- Tự động nhận diện tất cả các màn hình kết nối, chuẩn hóa theo từng mức DPI riêng biệt để ảnh chụp không bị mờ hay méo tỉ lệ.
- Giao diện chụp tương tác: Nhấp chuột vào màn hình bất kỳ hoặc nhấn phím số tương ứng (1..9) để chụp ngay màn hình đó.
- Nhận diện màn hình (Identify): Hiển thị số thứ tự các màn hình trong 2.5 giây rồi tự động ẩn.

2. Phím tắt toàn hệ thống linh hoạt
- Chụp tương tác từ bất kỳ đâu trên Windows (mặc định: Ctrl + Shift + X).
- Nhận diện màn hình (mặc định: Ctrl + Shift + ~).
- Chụp tức thì từng màn hình bằng tổ hợp phím bổ trợ + phím số [1..9] (mặc định: Ctrl + Shift + phím số màn hình).

3. Thư viện ảnh chụp (Gallery)
- Xem nhanh danh sách các ảnh đã chụp gần đây.
- Bấm đúp chuột để mở ảnh bằng trình xem mặc định của Windows.
- Hỗ trợ kéo và thả (Drag and Drop) ảnh trực tiếp từ thư viện vào các ứng dụng khác.

4. Tự động hóa sau khi chụp
- Tự động sao chép ảnh vào bảng tạm (Clipboard) ngay sau khi chụp.
- Tự động lưu ảnh vào thư mục cấu hình theo định dạng ngày giờ.

5. Tích hợp sâu vào hệ thống
- Chạy ẩn dưới khay hệ thống (System Tray), bấm chuột trái để chụp nhanh, bấm chuột phải để mở menu.
- Tùy chọn thu nhỏ xuống khay hệ thống khi bấm nút Minimize hoặc nút Close.
- Tùy chọn khởi động cùng Windows: Tắt, Bật, hoặc Bật ở chế độ thu nhỏ.
- Cơ chế Single Instance: Chặn mở trùng lặp nhiều tiến trình, tự động đưa cửa sổ đang chạy lên trên khi mở lại phần mềm.
- Cuộn mượt mà (Smooth Scrolling) học hỏi từ Lenovo Legion Toolkit.
- Hỗ trợ giao diện Sáng / Tối và đồng bộ màu nhấn (Accent Color) theo hệ thống Windows.

### Yêu cầu hệ thống
- Hệ điều hành: Windows (chắc chắn rồi).
- Môi trường thực thi: Microsoft .NET Desktop Runtime 9.0.

## English

### Introduction
LMScreenShot is a full-screen capture utility that helps users identify, interactively capture, or instantly capture individual displays separately.

### Key Features

1. Multi-Monitor Management and Interactive Capture
- Automatically detects all connected displays and scales per-monitor DPI so screenshots are never blurry or distorted.
- Interactive capture interface: Click on any screen or press the corresponding number key (1..9) to capture that screen immediately.
- Screen Identification (Identify): Displays the number of each screen for 2.5 seconds, then automatically hides.

2. Flexible System-wide Hotkeys
- Interactive capture from anywhere on Windows (default: Ctrl + Shift + X).
- Screen identification (default: Ctrl + Shift + ~).
- Instant capture for each monitor using modifier keys + number keys [1..9] (default: Ctrl + Shift + monitor number).

3. Image Gallery
- Quickly view recently captured screenshots.
- Double-click to open images with the default Windows viewer.
- Supports drag and drop directly from the gallery into other applications.

4. Post-Capture Automation
- Automatically copies the image to the clipboard immediately after capture.
- Automatically saves images to a configured folder using a timestamp format.

5. Deep System Integration
- Runs silently in the system tray: Left-click for quick capture, right-click to open the menu.
- Option to minimize to the system tray when clicking Minimize or Close.
- Start with Windows options: Disabled, Enabled, or Enabled Minimized.
- Single Instance mechanism: Prevents opening multiple instances, automatically brings the running window to the front when reopened.
- Smooth Scrolling inspired by Lenovo Legion Toolkit.
- Supports Light / Dark themes and syncs with the Windows system accent color.

### System Requirements
- Operating System: Windows (obviously).
- Runtime: Microsoft .NET Desktop Runtime 9.0.
